V49 · MODEL AUDIT

WHAT THIS ENGINE DOES
1. อ่าน STATE ก่อน
2. ใช้ SHORT + MID เป็นหลัก
3. ใช้ CHANGE ตรวจการเปลี่ยนเกม
4. State เปลี่ยน → ให้ข้อมูลใหม่มีน้ำหนักสูงขึ้น
5. ตัดสินใจ FOLLOW / CUT / WAIT
WHAT THIS ENGINE REMOVES
ตัด Pattern ที่ซ้ำซ้อนและไม่มีหลักฐานเพิ่ม
ตัดการตาม/สวน streak แบบอัตโนมัติ
ตัด historical analogy ออกจากตัวตัดสินหลัก
ตัดการนับโมเดลที่ใช้ข้อมูลเดียวกันเป็น evidence อิสระ
ตัด global penalty และเหลือ local audit
