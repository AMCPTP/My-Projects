V61 · CORE PRINCIPLES

หลักบังคับ
1. FULL REPLAY — ย้อนประวัติทั้งหมดเพื่อสร้างประสบการณ์ก่อน-หลังผลจริง
2. PREQUENTIAL — ทุก prediction ต้องเกิดก่อนผลจริงเท่านั้น
3. EXPERTS COMPETE — โมเดลแข่งกันด้วย log-loss/Brier + recent performance
4. REGIME-GATED — น้ำหนักต้องขึ้นกับสภาพเกมปัจจุบัน ไม่ใช้โมเดลเดียวทุกสถานการณ์
5. MEMORY HIERARCHY — short / medium / long ต้องเห็นตรงกันหรือมีเหตุผลว่าทำไมต่าง
6. PATTERN ≠ PROOF — exact/soft pattern เป็นหลักฐานเสริม ต้องมี sample + purity
7. ERROR LEDGER — แยก false reversal, missed continuation, tie miss, overconfidence
8. CALIBRATE — confidence ต้องถูกลดเมื่ออดีตพิสูจน์ว่าระบบมั่นใจเกินจริง
9. CHANGE-POINT FIRST — เมื่อ state เปลี่ยน ต้องลด trust ของ memory เก่าและเร่ง short memory
10. NO EDGE = WAIT — ถ้าไม่ชนะ baseline แบบ OOS อย่างสม่ำเสมอ ให้ยอมรับว่าไม่มี edge
คำเตือนเชิงสถิติ
ผล P/B/T เป็นลำดับผลลัพธ์ที่มีความไม่แน่นอนสูง ระบบนี้ใช้เพื่อวิเคราะห์และ audit วิธีคิด ไม่ใช่คำรับประกันผล
ความมั่นใจสูง = ความมั่นใจภายในข้อมูลย้อนหลังของระบบ ไม่ได้หมายความว่าผลถัดไปถูกกำหนดไว้แล้ว
การพบ pattern ซ้ำไม่ได้แปลว่ามี causal signal; V61 จะลดน้ำหนัก pattern เมื่อ sample น้อยหรือ purity ต่ำ
V61: จุดต่างหลักจาก V60 คือมี explicit online experience replay, regime-specific trust, probabilistic scoring, calibration, error taxonomy และ prequential audit เป็นวงจรเดียวกัน
