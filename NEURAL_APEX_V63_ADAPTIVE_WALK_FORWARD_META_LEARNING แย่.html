V63 · หลักการบังคับ

1. FULL REPLAY — ย้อนทุกตาเพื่อสร้าง state และประสบการณ์ก่อนผลจริง
2. PREQUENTIAL — prediction ของตาใดต้องใช้ข้อมูลก่อนตานั้นเท่านั้น
3. STATE BEFORE MODEL — จำแนกสภาพเกมก่อนเลือกวิธีวิเคราะห์
4. MIXTURE OF REGIMES — state อาจเป็นส่วนผสม ไม่บังคับว่าเป็นแบบเดียวเสมอ
5. STATE SIMILARITY — ค้นหาอดีตที่ “คล้ายกัน” ไม่ใช่เพียง sequence ที่ตรง 100%
6. EXPERT POLICY — เรียนรู้ว่า expert ไหนเก่งใน state แบบใด
7. REGRET LEARNING — วัดว่าที่เลือกมานั้นแพ้ expert อื่นมากแค่ไหน
8. ERROR TAXONOMY — แยก missed continuation / false reversal / tie miss / overconfidence
9. REPAIR POLICY — ความผิดพลาดชนิดเดิมต้องเปลี่ยนการให้น้ำหนักครั้งต่อไป
10. CALIBRATION — confidence ต้องสอดคล้องกับ hit จริง
11. COUNTERFACTUAL AUDIT — หลังจบประวัติ ต้องดูว่าตอนนั้น expert ตัวอื่นทำได้ดีกว่าหรือไม่
12. NO EDGE = WAIT — เมื่อ evidence ไม่ชนะ baseline แบบ out-of-sample ให้ลดความมั่นใจ
13. SAMPLE GATE — context/exact/state ที่มีตัวอย่างน้อยเกินไปจะไม่ถูกปล่อยให้ครอง ensemble
14. CHANGE-POINT ADAPT — เมื่อ distribution หรือ transition เปลี่ยน ให้ลดน้ำหนัก long-memory ชั่วคราว
15. DIVERSIFICATION — โมเดลที่ให้คำตอบซ้ำกันไม่ได้เพิ่มหลักฐานเป็นหลายเท่า
16. POST-UPDATE — ทุกตาต้อง update expert score, regret, error type และ calibration หลังรู้ผลจริง
17. COUNTERFACTUAL SAFETY — ห้ามอัปเกรด expert เพราะแค่ “ชนะล่าสุด”; ต้องดู loss + sample + state fit
18. ABSTENTION — เมื่อ disagreement สูง, sample ต่ำ หรือ OOS แพ้ baseline ให้หยุดคาดการณ์เชิงมั่นใจ
หมายเหตุ: V63 เป็นระบบวิเคราะห์เชิงสถิติจากลำดับ P/B/T ไม่ใช่เครื่องทำนายผลที่รับประกันอนาคต โดยเฉพาะข้อมูลที่มีความสุ่มสูง ความได้เปรียบใด ๆ ต้องพิสูจน์ด้วย out-of-sample และต้องยอมรับ “NO EDGE / WAIT” เมื่อหลักฐานไม่แข็งแรง
