V66 · หลักการบังคับ

1. WALK-FORWARD — ทุก prediction ใช้เฉพาะประวัติก่อนตานั้น; replay ใหม่ทุกครั้งเมื่อประวัติเปลี่ยน
2. CONTEXT TREE — เปรียบเทียบ context 1…8 และหดกลับเมื่อ context ยาวมี sample น้อย
3. BAYESIAN SHRINKAGE — pattern ที่เจอน้อยจะถูกดึงกลับเข้าหา baseline แทนการหลง pattern
4. PROBABILITY FIRST — ทุก expert ให้ probability distribution แล้ววัดด้วย log-loss/Brier
5. CONTEXTUAL EWA — expert ที่ดี “ใน state/regime นี้” ได้ weight มากกว่า expert ที่ดีเพียงทั้งประวัติ
6. FIXED-SHARE ADAPTATION — เมื่อ regime เปลี่ยน เปิดทางให้ weight กลับไปหา expert อื่น ไม่ติดกับโมเดลเดิม
7. CHANGE-POINT — ตรวจทั้ง distribution และ transition; เมื่อเปลี่ยนให้ลด long-memory และเพิ่ม local evidence
8. RUN-HAZARD — เรียนรู้โอกาสต่อ/เปลี่ยนตามความยาว run จากประวัติจริง ไม่ใช้เลข 0.60/0.55 แบบตายตัว
9. SOFT SIMILARITY + STATE KNN — ใช้บริบทคล้ายกันโดยถ่วงน้ำหนักตาม similarity และอายุข้อมูล
10. REDUNDANCY CONTROL — โมเดลที่มีข้อมูลแหล่งเดียวกันไม่ควรถูกนับเป็นหลักฐานหลายเท่า
11. NOVELTY / OOD — ถ้าปัจจุบันไม่คล้ายอดีตพอ ระบบจะรู้ว่า “ไม่เคยเห็น state นี้มาก่อน” และลดความมั่นใจ
12. ERROR-LOCAL MEMORY — แยกความผิดพลาดตาม regime และ expert เพื่อไม่แก้ทั้งระบบเพราะความผิดพลาดจาก state เดียว
13. COUNTERFACTUAL — หลังรู้ผล ให้ดูว่า expert ใดเสีย loss ต่ำกว่าในตานั้น และนับการไล่ทัน oracle
14. CALIBRATION — confidence ต้องพิสูจน์จากผลจริงแบบ walk-forward; high confidence ที่ผิดซ้ำจะถูกลด
15. ABSTENTION — evidence ต่ำ, OOD สูง, disagreement สูง หรือ OOS แพ้ baseline = WAIT/CUT
16. NO MAGIC — ไม่มีวิธีทำให้ลำดับที่สุ่มกลายเป็นข้อมูลที่ทำนายได้แน่นอน; เป้าหมายคือแยก signal ออกจาก noise และรู้ว่าเมื่อไร “ไม่รู้”
