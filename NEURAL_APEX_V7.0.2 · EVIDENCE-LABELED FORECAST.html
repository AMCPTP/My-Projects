NEURAL APEX V7.0.2 · EVIDENCE-LABELED FORECAST

ระบบย้อนดู เปรียบเทียบ และวิเคราะห์ประวัติทั้งหมดเพื่อวิเคราะห์ทุกตาหลังมีข้อมูล และประกาศ FORECAST เมื่อถึงเกณฑ์ 60% ขึ้นไป โดยแสดงที่มาของสัญญาณ ความน่าจะเป็น และระดับหลักฐานอย่างตรงไปตรงมา; ACTION เป็นชั้นคัดกรองที่เข้มกว่า FORECAST

กฎหลัก V7.0.2: ① ใช้เฉพาะประวัติที่บันทึกจริง ② วิเคราะห์ทุกตาที่มีข้อมูล โดยใช้ Exact / Pattern / Context ก่อน และ historical baseline เมื่อยังไม่มี match ③ ประกาศ FORECAST เฉพาะเมื่อความน่าจะเป็นของตัวเลือกหลัก ≥ 60%; ต่ำกว่า 60% ให้ WAIT และไม่ฝืนทาย ④ แสดง source, posterior และ evidence quality ทุกครั้ง จึงไม่ปกปิดความอ่อนของหลักฐาน ⑤ ใช้ Bayesian smoothing กับ effective sample size ⑥ ตรวจ conflict / stability / robustness ⑦ ตรา ACTION มีเฉพาะ forecast ที่ผ่านเกณฑ์เข้ม; โดยต่ำกว่า 60% เป็น WAIT; ACTION ยังเป็นชั้นเข้มกว่า FORECAST ⑧ วิเคราะห์ P/B/T แยกจาก P/B action ⑨ Backtest แบบ expanding-window เทียบ baseline ที่ใช้ได้ ณ เวลานั้น และนับเฉพาะ forecast ที่ผ่าน 60% ⑩ รายงาน forecast hit rate, interval, Brier, log loss และ calibration ⑪ เพิ่ม transition, streak, regime, drift และ 2-step scenario โดยใช้เฉพาะข้อมูลย้อนหลังจริง
