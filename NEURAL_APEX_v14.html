PATTERN ENGINE · รูปแบบ P / B

ตรวจรูปแบบที่กำหนดจากผล P/B จริง โดย T ไม่ถูกนับเป็น P/B ของ pattern. สถิติย้อนหลังใช้เฉพาะเหตุการณ์ที่ pattern ปรากฏก่อนผลถัดไป เพื่อรักษา walk-forward และไม่ใช้ผลอนาคต; Pattern Engine เป็น research-only และไม่มีผลต่อ V9.1 decision.

PATTERN READ · ตรวจครบทุก Pattern ที่เปิดใช้งานรอข้อมูล
PATTERN FORECAST · คาดการณ์จาก Pattern ที่ตรงกันรอข้อมูล
PATTERN ENSEMBLE · รวมคะแนนจาก Pattern ที่ตรงกันรอข้อมูล
