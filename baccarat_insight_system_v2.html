ขอบเขตความสามารถของระบบ

ทำงานแล้ว · สถิติผล B/PWin Rate, Streak, Chop, Rolling Window, Transition Analysis และ Pattern Scanner คำนวณใหม่ทุกครั้งที่เพิ่ม/ย้อนกลับ/รีเซ็ต
ทำงานแล้ว · Road MapBead Plate, Big Road และ Derived Roads ทั้ง 3 ชนิดสร้างจากข้อมูลชุดเดียวกัน โดยแก้การวางมังกรและจุดเริ่มต้นของเค้าไพ่
ทำงานแบบทดลอง · Forecastใช้ดัชนีแบบถ่วงน้ำหนักและดึงค่ากลับสู่ค่าฐานเพื่อสรุปแนวโน้ม ไม่ใช่ความน่าจะเป็นจริง และยังไม่ผ่านการยืนยันจากข้อมูลอิสระ
ทำงานแล้ว · Walk-forward Backtestสร้างคำทายจากข้อมูลก่อนหน้าเท่านั้น และประเมินเฉพาะรอบที่โมเดลแสดงสัญญาณ พร้อมแสดง Coverage และค่าฐานเปรียบเทียบ
ยังไม่ทำงาน · Card Counting / Shoe Compositionปุ่ม B/P ไม่ได้เก็บแต้มไพ่รายใบ จึงยังคำนวณไพ่ที่เหลืออยู่หรือ Running Count ไม่ได้ ต้องมีระบบป้อนแต้มไพ่และจำนวนสำรับ
ยังไม่ทำงาน · Shuffle Tracking / Edge Sortingต้องอาศัยข้อมูลการสับไพ่หรือคุณลักษณะทางกายภาพของไพ่ ซึ่งไม่มีอยู่ในประวัติ B/P
ยังไม่ทำงาน · Monte Carlo Simulation / Machine Learningเวอร์ชันนี้มี Backtest เท่านั้น ยังไม่มีการจำลองแจกไพ่จาก Shoe หรือฝึกโมเดล Machine Learning
คำเตือน · Betting Systems / Risk ManagementMartingale, Fibonacci, Paroli และสูตรอื่นเปลี่ยนขนาดเดิมพัน ไม่ได้เพิ่มโอกาสชนะหรือกำจัด House Edge
ข้อจำกัดสำคัญ: เวอร์ชันนี้บันทึกเฉพาะ B/P จึงยังไม่มี Tie ใน Bead Plate และสถิติจะคิดจากผลที่ตัดสินแล้วเท่านั้น ข้อมูลต้องมาจาก Shoe เดียวกันหากต้องการอ่าน Road Map ของ Shoe นั้นอย่างถูกต้อง
